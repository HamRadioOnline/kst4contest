# Contributing to KST4Contest

Thanks for taking the time to contribute! Every thoughtful bug report, documentation improvement, and code change makes this project better.

Repository: [KST4Contest](https://github.com/HamRadioOnline/kst4contest).

Target branch: main.

## Development setup

1. Fork the repository and clone your fork.
2. Install the project's documented prerequisites and dependencies.
3. Create a branch for your change.
4. Commit your change in a linear way.

## Pull requests

Keep pull requests focused on one change. Explain the problem, your approach, and how you tested it. Link any related issues and respond to review feedback constructively. Please also commit your changes in a linear way, it helps us to better deal with your changes. Please also start your pull request from a feature or change branch.

## Beyond code

Code is only one way to help. You can improve documentation, reproduce an issue, suggest clearer wording, help someone get started or help with translation of this project.
